# GRC Risk Register & Dashboard

تطبيق ويب عربي لإدارة سجل المخاطر التقنية والأمنية، مصمم كنسخة MVP قابلة للنشر على Vercel.

## الوظائف الحالية

- لوحة مؤشرات للمخاطر.
- سجل مخاطر تفاعلي.
- إضافة وتعديل وحذف المخاطر.
- حساب درجة الخطر تلقائيًا: الاحتمالية × التأثير.
- تصنيف مستوى الخطر: منخفض، متوسط، عالي، حرج.
- رسوم بيانية حسب الحالة والتصنيف ومستوى الخطر.
- تخزين مؤقت في المتصفح باستخدام LocalStorage.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## النشر

ارفع المشروع إلى GitHub ثم اربطه بـ Vercel.
